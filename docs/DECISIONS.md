# Decision Log

## D-001 — Preservation gate before enhancement
**Status:** Accepted

No HD art, mobile UI or new gameplay features before original gameplay parity is demonstrated.

## D-002 — Portable deterministic core
**Status:** Accepted

Recovered gameplay logic will be isolated from rendering, input devices and platform APIs.

## D-003 — Public repo excludes original commercial payloads
**Status:** Accepted

Original executables/assets/data remain local/private unless redistribution rights explicitly allow publication.

## D-004 — Analyse Windows build first when available
**Status:** Accepted

Use the PE32 Windows executable as the initial static-analysis target where practical, then cross-check DOS behaviour/tables.
